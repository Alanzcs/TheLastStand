# The Last Stand

![Game Screenshot](/gameplay/screenshot.png)

## Опис на играта
"The Last Stand" е 2D акциона игра за преживување каде што играчот мора да се бори против напади на зомбиња и да преживува што е можно подолго. Играта вклучува:
- Бранови од различни видови на зомбиња (фрлачи, танкови, брзи зомбиња)
- Босови на секое 5-то ниво
- Собирање на прва помош пакети за зголемување на животот
- Избегнување на токсични барели
- Систем со нивоа каде после секое ниво играта станува потешка и потешка

## Контроли
- **W, A, S, D**: Движење
- **Space**: Пукање
- **R**: Рестарт на играта по смрт
- **Q**: Излез од играта по смрт

## Инсталација
1. Потребни се:
   - Python 3.x
   - Библиотеки: `pygame`, `PIL`
   
2. Инсталирај ги зависностите:
```bash
pip install pygame pillow
```
